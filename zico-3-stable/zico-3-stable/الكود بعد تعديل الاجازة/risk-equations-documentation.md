# 📐 جميع معادلات حساب المخاطرة في منصة WADJET GRC

---

## أولاً: حساب التأثير (Impact Calculation)

### 1. استخراج قيم التأثير (impactValues)
```
القيمة = form.impacts[criterion_name]
```
**الشرح:** نستخرج قيمة كل معيار تأثير (1-5) من الفورم. لو القيمة مش موجودة أو خارج النطاق، نرجع 1.

---

### 2. مجموع قيم التأثير (impactSum)
```
المجموع = Σ قيمة_كل_معيار
```
**الشرح:** نجمع كل قيم المعايير الثمانية (Financial, Regulatory, Reputational, Safety, Operational, Confidentiality, Integrity, Availability).

---

### 3. التأثير المرجح (Weighted Impact) - calculateWeightedImpact
```
التأثير_المرجح = Σ (القيمة × الوزن) / Σ الأوزان
```
**الشرح:** 
- نضرب كل قيمة في وزنها المقابل
- نجمع النواتج ونقسم على مجموع الأوزان
- النتيجة تقرب لأقرب عدد صحيح وتحدد بين 1-5
- لو الأوزان صفر، يرجع لأقصى قيمة (Max)

---

### 4. أقصى تأثير (Max Impact) - calculateMaxImpact
```
التأثير_الأقصى = max(قيمة_كل_معيار)
```
**الشرح:** ناخذ أعلى قيمة بين كل معايير التأثير. الطريقة الأبسط.

---

### 5. التأثير الممزوج (Advanced/Blended) - blendedImpact
```
التأثير_الممزوج = 0.7 × الأقصى + 0.3 × المتوسط_المرجح
```
**الشرح:**
- 70% من أقصى قيمة تأثير
- 30% من المتوسط المرجح للقيم
- النتيجة تقرب وتحدد بين 1-5
- هذه طريقة "Advanced 70/30" في الإعدادات

---

### 6. حساب التأثير النهائي (impactFor)
```
لو الطريقة = "advanced" → التأثير_الممزوج
لو الطريقة = "weighted" → التأثير_المرجح
لو الطريقة = "max" → التأثير_الأقصى
```
**الشرح:** حسب إعدادات الدومين، نختار طريقة حساب التأثير المناسبة.

---

## ثانياً: حساب درجة المخاطرة (Risk Score)

### 7. درجة المخاطرة الذاتية (Inherent Risk Score) - calculateInherentScore
```
الدرجة_الذاتية = الاحتمالية × التأثير
```
**الشرح:**
- الاحتمالية (Likelihood): من 1 إلى 5
- التأثير (Impact): من 1 إلى 5
- النتيجة: من 1 إلى 25
- هذه الدرجة قبل أي ضوابط

---

### 8. درجة المخاطرة بالضرب المرجح (Weighted Additive)
```
الدرجة = (وزن_الاحتمالية × الاحتمالية + وزن_التأثير × التأثير) × 5
```
**الشرح:**
- أوزان الاحتمالية والتأثير تُحدد من إعدادات الباراميتر
- الافتراضي: 0.5 لكل منهما
- النتيجة تقرب وتحدد بين 1-25
- المجموع يجب أن يساوي 1 (±0.001)

---

### 9. درجة المخاطرة من المصفوفة (Matrix Lookup)
```
الدرجة = matrixLookupTable[الاحتمالية-1][التأثير-1]
```
**الشرح:**
- نبحث في جدول 5×5 مُعرّف في إعدادات الباراميتر
- الصف = الاحتمالية، العمود = التأثير
- لو المصفوفة ناقصة، يرجع للضرب العادي (L × I)

---

### 10. حساب درجة المخاطرة النهائية (riskScoreFor)
```
الطريقة المتعددة (multiplicative): الاحتمالية × التأثير
الطريقة المرجحة (weighted_additive): (wL×L + wI×I) × 5
طريقة المصفوفة (matrix_lookup): من الجدول
```
**الشرح:** نفس المعادلات السابقة مجمعة في دالة واحدة.

---

## ثالثاً: حساب فعالية الرقابة (Control Effectiveness)

### 11. معامل فعالية الرقابة المركب (cefFor)
```
CE_combined = 1 - Π(1 - CE_i)
```
**الشرح:**
- لكل رقابة فعالة (existing/mitigating)
- نضرب (1 - قيمة_الفعالية) لكل الرقابات
- النتيجة من 1 - هذا الضرب
- لا تتجاوز الحد الأقصى (residualCapReduction)
- القيم الافتراضية:
  - Effective: 0.75
  - Partially Effective: 0.5
  - Ineffective: 0.25
  - Not Assessed: 0

---

### 12. فعالية الرقابة المركبة بالمحاور (calculateCombinedCE)
```
نفس المعادلة: CE_combined = 1 - Π(1 - CE_i)
```
**الشرح:** نفس السابقة لكن مع فلترة حسب نوع الرقابة:
- **Preventive**: تقلل الاحتمالية فقط
- **Detective**: تقلل التأثير فقط
- **Corrective**: تقلل التأثير فقط
- **Other**: تقلل كلا المحورين

---

## رابعاً: حساب المخاطرة المتبقية (Residual Risk)

### 13. المخاطرة المتبقية المقترحة (suggestedResidual)
```
المتبقية = الدرجة_الذاتية × (1 - CE_combined)
```
**الشرح:**
- نضرب درجة المخاطرة الذاتية في (1 - فعالية الرقابة)
- النتيجة لا تقل عن 1
- هذه القيمة المقترحة تلقائياً من النظام

---

### 14. المخاطرة المتبقية بالمحاور (residualAxesFor)
```
CE_الاحتمالية = 1 - Π(1 - CE_i) للرقابات الوقائية
CE_التأثير = 1 - Π(1 - CE_i) للرقابات الاستكشافية/التصحيحية

الاحتمالية_المتبقية = الاحتمالية × (1 - CE_الاحتمالية)
التأثير_المتبقي = التأثير × (1 - CE_التأثير)

الدرجة_المتبقية = الاحتمالية_المتبقية × التأثير_المتبقي
```
**الشرح (ISO 27005):**
- الرقابات الوقائية تقلل احتمالية الحدوث
- الرقابات الاستكشافية/التصحيحية تقلل تأثير الحدث
- كل محور يُحسب بشكل مستقل
- النتيجة النهائية من ضرب المحورين المتبقيين

---

### 15. المخاطرة المتبقية البسيطة (calculateSimpleResidualRisk)
```
المتبقية = الدرجة_الذاتية × (1 - CE_overall)
```
**الشرح:** الطريقة القديمة/البسيطة حيث الرقابة تقلل الدرجة مباشرة بدون تمييز بين المحاور.

---

## خامساً: تحديد مستوى الخطورة (Risk Level)

### 16. معادلة تحديد المستوى (levelOf)
```
لو الدرجة ≥ الحرج (20) → Critical
لو الدرجة ≥ العالي (12) → High
لو الدرجة ≥ المتوسط (6) → Medium
غير ذلك → Low
```
**الشرح:**
- العتبات قابلة للتخصيص من إعدادات الباراميتر
- الافتراضي: Critical=20, High=12, Medium=6
- تُحسب على الدرجة الذاتية والمتبقية

---

## سادساً: حالة الشهية (Appetite Status)

### 17. معادلة حالة الشهية
```
لو المتبقية ≤ حد_الشهية → "Within Appetite"
لو المتبقية > حد_الشهية → "Exceeds Appetite"
```
**الشرح:**
- حد الشهية (appetiteLimit) يُحدد في إعدادات الباراميتر
- الافتراضي: 12
- يُقارن بدرجة المخاطرة المتبقية

---

## سابعاً: نسبة الانحراف والتبرير

### 18. نسبة الانحراف (deviationRatio)
```
النسبة = |القيمة_المدخلة - المقترحة| / المقترحة
```
**الشرح:**
- تقيس الفرق بين ما أدخله المستخدم وما اقترحه النظام
- لو المقترحة صفر والمدخلة > صفر → Infinity
- لو المقترحة صفر والمدخلة صفر → 0

---

### 19. شرط التبرير (requiresJustification)
```
يتطلب_تبرير = نسبة_الانحراف > 0.2 (20%)
```
**الشرح:**
- لو المستخدم غيّر القيمة بأكثر من 20% عن المقترح
- يجب عليه كتابة تبرير (20 حرف حد أدنى)
- هذا يمنع التلاعب في الدرجات

---

## ثامناً: الدالة الرئيسية (computeRiskScore)

### 20. الحساب الشامل (computeRiskScore)
هذه الدالة الرئيسية التي تجمع كل المعادلات:

```
1. التحقق من صحة الأوزان (مجموعها = 1 ± 0.005)
2. حساب التأثير (weighted/max)
3. حساب الدرجة الذاتية (multiplicative/weighted_additive/matrix_lookup)
4. حساب فعالية الرقابة المركبة
5. حساب المخاطرة المتبقية
6. تحديد مستوى الخطورة
7. تحديد حالة الشهية
```
**تُرجع:**
```javascript
{
  impact,           // التأثير النهائي (1-5)
  inherentScore,    // الدرجة الذاتية (1-25)
  inherentLevel,    // مستوى الخطورة الذاتية
  combinedCE,       // فعالية الرقابة المركبة (0-1)
  residualScore,    // المخاطرة المتبقية (1-25)
  residualLevel,    // مستوى المخاطرة المتبقية
  appetiteStatus,   // حالة الشهية
  scoredWithParameter // بيانات الباراميتر وقت الحساب
}
```

## تاسعاً: معادلات مساعدة أخرى

### 21. التحقق من المقياس 1-5 (validateScale15)
```
لو القيمة ليست عدد صحيح بين 1-5 → خطأ
```
**الشرح:** نتأكد إن كل القيم (احتمالية، تأثير) ضمن النطاق المسموح.

---

### 22. التحقق من فعالية الرقابة 0-100 (validateCE)
```
لو القيمة ليست رقم بين 0-100 → خطأ
```
**الشرح:** نتأكد إن نسبة فعالية الرقابة ضمن النطاق.

---

### 23. مساهمة كل معيار (Contribution)
```
المساهمة = الوزن × القيمة
```
**الشرح:** تظهر في الواجهة بجانب كل معيار تأثير.

---

### 24. الحد الأقصى للتخفيض (Residual Cap)
```
التخفيض_الفعلي = min(CE_المحسوب, residualCapReduction)
```
**الشرح:**
- لا يمكن للرقابات أن تخفض المخاطرة أكثر من الحد المسموح
- الافتراضي: 0.75 (75% حد أقصى للتخفيض)
- يمنع إدخال رقابات غير واقعية

## ملخص المتغيرات المستخدمة

| المتغير | المعنى | النطاق |
|---------|--------|--------|
| L | الاحتمالية (Likelihood) | 1-5 |
| I | التأثير (Impact) | 1-5 |
| wL | وزن الاحتمالية | 0-1 |
| wI | وزن التأثير | 0-1 |
| CE | فعالية الرقابة | 0-1 |
| SCALE_FACTOR | معامل المقياس | 5 |
| thresholds | عتبات الخطورة | Critical=20, High=12, Medium=6 |
| appetiteLimit | حد الشهية | 12 (افتراضي) |
| residualCapReduction | أقصى تخفيض | 0.75 (افتراضي) |

---

## ملخص سير العمل

```
1. المستخدم يدخل الاحتمالية (1-5)
2. المستخدم يدخل قيم التأثير لكل معيار (1-5)
3. النظام يحسب التأثير حسب إعدادات الدومين (weighted/max/advanced)
4. النظام يحسب الدرجة الذاتية (L × I)
5. النظام يحسب فعالية الرقابة من المرتبطة
6. النظام يحسب المخاطرة المتبقية (الدرجة × (1 - CE))
7. النظام يحدد مستوى الخطورة (Critical/High/Medium/Low)
8. النظام يقارن بحد الشهية
9. لو المستخدم غيّر القيمة ب >20% → يُطلب تبرير
```
